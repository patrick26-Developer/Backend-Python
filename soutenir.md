# Contribuer / suivre le projet

Cette formation est **gratuite et en accès libre**. Si elle t'a été utile, voici comment
aider sans qu'il y ait rien à payer :

- **⭐ Mets une étoile** sur le [dépôt GitHub](https://github.com/patrick26-Developer/Backend-Python)
  — ça aide d'autres personnes à le trouver.
- **Signale une erreur ou une amélioration** via une [issue GitHub](https://github.com/patrick26-Developer/Backend-Python/issues).
- **Propose une correction** via une *pull request* — voir [`CONTRIBUTING.md`](CONTRIBUTING.md).
- **Partage-le** à quelqu'un qui apprend FastAPI.
- **Suis le travail** sur le [portfolio de l'auteur](https://portfolio-personnel-ecru.vercel.app/).

## Licence — ce que tu peux en faire

- **Code** (`taskman/`, les solutions, les tests) : licence **MIT** — réutilise-le
  librement, y compris dans un projet commercial.
- **Contenu pédagogique** (théorie, explications, énoncés) : **tous droits réservés**,
  lecture et apprentissage libres — mais **pas de revente ni de republication** de ce
  contenu ailleurs sous ton nom. Détails : [`LICENSING.md`](LICENSING.md).
